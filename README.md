# GoldFVGAlarm — هشدار FVG سه‌کندلی طلا (تایم ۱۵ دقیقه)

اپ اندروید (Kotlin + Jetpack Compose) که کندل‌های ۱۵ دقیقه‌ای طلا را پایش می‌کند و به محض
برخورد قیمت با یک FVG سه‌کندلی، آژیر پlooping پخش می‌کند تا کاربر آن را قطع کند.

## قواعد پیاده‌سازی‌شده
- **FVG سه‌کندلی**: کندل ۱ و ۳ بدون هم‌پوشانی (صعودی: low کندل۳ > high کندل۱؛ نزولی برعکس).
- **فقط تایم ۱۵ دقیقه.**
- **کنسل شدن**: اگر یک کندل ۱۵ دقیقه‌ای **بیرون** از ناحیه FVG کلوز دهد، آن FVG کنسل می‌شود.
- **هشدار**: با اولین touch قیمت به ناحیه، آژیر + ویبره + نوتیفیکیشن full-screen؛ صدا با MediaPlayer
  looping پخش می‌شود و فقط با دکمه «قطع صدا» (در اپ یا داخل نوتیفیکیشن) متوقف می‌شود.
- **کارکرد با بسته بودن اپ**: Foreground Service با WakeLock هر ۴۵ ثانیه دیتا را چک می‌کند و بعد از
  ری‌استارت گوشی هم به‌خودی‌خود اجرا می‌شود (BootReceiver).

## منبع دیتا: OANDA
دیتای طلا (XAU_USD اسپات) از **OANDA v20 REST API** گرفته می‌شود (حساب Practice رایگان).
1. در oanda.com یک حساب Practice بساز.
2. از myaccount.oanda.com وارد بخش **Manage API Access** شو و توکن بگیر.
3. توکن را در اولین اجرای اپ وارد کن و ذخیره بزن (فقط روی گوشی خودت ذخیره می‌شود).
برای حساب لایو، آدرس `api-fxpractice` در `PriceFetcher.kt` را به `api-fxtrade` تغییر بده.
توجه: اگر OANDA برای تو در دسترس نیست، نسخه‌ی چندمنبعی (بدون توکن) را بگیر.

## ساخت و اجرا
1. پوشه پروژه را با **Android Studio** باز کنید (Hedgehog یا جدیدتر).
2. صبر کنید Gradle Sync تمام شود.
3. گوشی را با USB وصل کنید (Developer Options > USB Debugging روشن) و Run بزنید.

## تنظیمات مهم برای ۲۴/۷ کارکرد
1. **غیرفعال کردن بهینه‌سازی باتری** برای این اپ: Settings > Apps > هشدار FVG طلا > Battery > Unrestricted
2. اجازه‌ی **نوتیفیکیشن** را بدهید (پنجره‌اش داخل اپ باز می‌شود).
3. روی بعضی گوشی‌های شیائومی/هواوی علاوه بر این، «اجازه‌ی اجرا در پس‌زمینه» و «قفل اپ در Recent Apps» را هم فعال کنید.
4. برای قطعی‌ترین حالت ۲۴ ساعته، بهتر است یک اسکریپت سرور (VPS) هم داشته باشید که همین منطق را اجرا
   کند و از طریق تلگرام/FCM به گوشی خبر بدهد — بگو تا آن را هم آماده کنم.

## ساختار
- `AlertService.kt` — سرویس پس‌زمینه، پولینگ، آژیر و نوتیفیکیشن
- `FvgDetector.kt` — منطق سه‌کندلی
- `PriceFetcher.kt` — دریافت کندل‌های ۱۵ دقیقه‌ای از OANDA
- `FvgStore.kt` — ذخیره FVGهای فعال
- `PriceChart.kt` / `MainActivity.kt` — رابط کاربری و چارت

> توجه: این ابزار صرفاً برای هشدار تکنیکال است و توصیه مالی محسوب نمی‌شود.

## ساخت APK بدون کامپیوتر — با GitHub Actions
1. پروژه را در یک ریپوی GitHub آپلود کن (همه فایل‌ها از جمله پوشه‌ی `.github`).
2. تب **Actions** را باز کن — workflow به‌نام «Build APK» خودش اجرا می‌شود (یا دکمه‌ی Run workflow را بزن).
3. بعد از تمام شدن (چند دقیقه)، وارد همان اجرا شو و در بخش **Artifacts** فایل `GoldFVGAlarm-APK` را دانلود کن — همین APK را روی گوشی نصب کن.
